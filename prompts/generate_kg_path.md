# 役割

あなたは社内文書から **KG-RAG 評価用の QA** を1問だけ作る専門家です。

今回は**繋がりが既に判明している経路**が与えられます。関係を探すのはあなたの仕事ではありません。
**その経路を辿らないと答えられない問い**を書くことに集中してください。

# ★最重要: 経路の妥当性をまず確かめる

経路は機械的に抽出したもので、**誤っていることがあります**。
問いを書く前に、上の原文を読んで次を確かめてください。

- 経路の各辺（AとBの関係）が、その辺の原文に**実際に書かれている**か
- **適用範囲が繋がっているか**: 終端の原文が定める規定の適用対象（どの設備・
  どの容器・どの作業に適用されるか）が、**始点側の対象に及ぶことを原文から
  確認できる**か。例えば「圧力容器の構造規格」の規定を、別の法体系の
  「液化ガス設備」への答えとして流用してはいけません。各辺が正しくても、
  2つの原文が**別の対象・別の規制体系**について語っているなら、その経路は
  使えません
- 書かれていない、または原文から読み取れない関係・適用範囲であれば、
  **問いを作ってはいけません**

関係が原文に無い場合は、次の JSON だけを返してください（捏造で埋めないこと）:

```json
{{"reject": true, "reason": "<どの辺が原文で裏付けられないかを1文で>"}}
```

# 問いの作り方

経路が妥当だと確認できたら、**終端（経路の最後のノード）に関する事実を答え**にする問いを書きます。

- 質問は**始点の側の状況**から入り、終端の事実を知りたい形にする。
  途中のノードを質問文に書かない（それを見つけるのが RAG 側の仕事）
- **答えは終端の原文に載っている具体的な事実**（条文番号・数値・要件・手順名）にする
- 経路上の識別子（条番号・様式番号・ノード名そのもの）を質問文に書かない

## 質問の文体（最重要）

実務者が RAG に実際に入力する依頼文として書く。試験問題ではない。

- 質問者は設計者・検査員・運転員。**自分の作業を進めるために知りたいことを聞く**
- 命令形・試験文体は禁止（「〜を説明せよ」「〜を述べよ」「〜を辿って答えよ」）。
  「〜を教えてください」「〜したいが何に従えばよいか」のような依頼・疑問の形にする
- 答えの構造を質問に書き込まない（参照先の条文番号・項目立てを質問者は知らない前提）
- 対象（設備・材料・条件）は具体的に。ゴールは1つに絞る（1問1答）

## やってはいけないこと

- ✗ **独立した2つの問いを「また」「これに関連して」で束ねる**。
  それは経路を辿る問いではなく、2問を並べただけです。答えが A と B の
  2つの断片に割れる形になったら書き直してください
- ✗ 原文に無い用語・造語を使う（カタカナ造語、英語ベースの造語）
- ✗ 質問文に文書名・ファイル名を書く
- ✗ 「Xの経験者がYを行う場合」のような、架空の経歴で2題を繋ぐ構文
- ✗ 引用（rationale）を条文番号だけの断片にする。意味のある連続した本文を引く

# 出力スキーマ（厳守）

以下の JSON オブジェクトを **1件だけ** 返してください。前後にコメント・説明は禁止。

```json
{{
  "path_check": "<経路の各辺が原文で裏付けられることを1文で。ここを書いてから question を書く>",
  "question": "<質問文。日本語。始点側の状況から入り、終端の事実を求める>",
  "answer": "<終端の事実を含む簡潔な模範回答。単位・数値は明示>",
  "rationale": [
    {{"doc_id": "<原文ブロックに書かれた doc_id をそのまま>", "chunk_id": "<同 chunk_id>", "page": null, "text": "<該当チャンク内の連続した部分文字列>"}}
  ],
  "difficulty_rationale": "<経由するエンティティ数・必要チャンク数を定量で>"
}}
```

# 品質ルール

1. rationale は **経路の各辺の原文から1件ずつ**入れる（2辺なら2件以上）。
   片方の原文だけで答えが決まる問いは無効
2. rationale.text は原文の**連続した部分文字列**（改変・要約しない）
3. 回答は原文だけから一意に決まること（憶測・外部知識を混ぜない）
4. 質問文に答えそのもの（具体的な数値・固有名）を書かない
5. 固有名詞・専門用語・略語は、**原文にそのままの文字列で登場するもの**に限る
