# 役割

あなたは知識グラフの検証者です。この呼び出しでは**判定だけ**を行います。
問題や回答を書いてはいけません。

# 与えられた星型（1つの対象に複数の要素がぶら下がる形）

{star_block}

# 各要素の裏付けとされる原文

{evidence_block}

# 判定すること

これらの要素が、**同じ対象・同じ規定のもとで並ぶ1つの集合**として成り立つか。

判定基準:

1. 各要素と中心の関係が、その原文に実際に書かれているか
2. **文脈が揃っているか**: 全要素が同じ対象・同じ条件・同じ規定に属するか。
   例えば別々の講習の科目、別々の設備区分の要件が混ざっていたら不成立
3. 常識や外部知識で補ってはいけない。原文に書かれていることだけで判定する

要素の一部だけが別文脈なら、その要素名を excluded に挙げて残りで判定してよい。

# 出力（どちらか一方の JSON だけを返す。前後に説明を書かない）

成り立つ場合:

```json
{{"valid": true, "relation": "<中心と要素集合の関係を1文で。例: 容器保安規則により、附属品検査は外観検査・耐圧試験・気密試験…の項目で行うことが定められている>", "excluded": ["<別文脈として除いた要素名。無ければ空>"]}}
```

成り立たない場合:

```json
{{"valid": false, "reason": "<どの要素の文脈が揃わないかを1文で>"}}
```
